# Privacy Policy — Market Sketchbook Bot

**Last updated:** 23 October 2026

This is a personal, single-user automation project. It is not distributed to
or used by anyone other than its owner, and it is not a public service or
product.

## What this app does

Market Sketchbook Bot generates daily FII/DII (Foreign/Domestic Institutional
Investor) market data videos and uploads them, via the YouTube Data API, to
**the owner's own YouTube channel only**. It uses the
`https://www.googleapis.com/auth/youtube.upload` OAuth scope solely to upload
videos created by the owner to the owner's own channel.

## Data accessed

- The app only accesses the YouTube channel of the Google account that
  authorized it.
- The app does not read, access, or process any other user's YouTube data,
  Google account data, or personal information.
- No data obtained through the Google/YouTube API is sold, shared, transferred,
  or used for advertising, and none of it is used to train AI/ML models.

## Data storage

- An OAuth refresh token is stored privately as an encrypted secret in the
  owner's GitHub repository settings and the owner's local environment. It is
  never committed to source control or shared with any third party.
- No other personal data is collected or stored by this app.

## Contact

For questions about this project, contact the repository owner via the
contact details on the associated GitHub account.
